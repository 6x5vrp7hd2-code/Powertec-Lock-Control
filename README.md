# Powertec Electrical Safety Asset Control — demonstration

## GitHub Pages upload
Upload **all five files** from this directory to the **root** of the GitHub repository:
- `index.html`
- `styles.css`
- `app.js`
- `lv-reference.jpg`
- `README.md`

No folders are required. In repository **Settings → Pages**, choose **Deploy from a branch**, `main`, `/(root)` and save.

## Safety and privacy
This is a demonstration only. Data is stored in the current browser's localStorage and is not shared between devices. Do not enter actual electrical isolation details, key custody records, permit data, personal information, or sensitive site drawings into a publicly hosted demo. The included image is a provisional photograph-derived reference, not a verified electrical drawing. The application is not approved for electrical safety control, document issuance or key release.
